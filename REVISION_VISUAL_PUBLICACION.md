# Revisión visual previa a publicación — FranQuestions

Esta lista comprueba la experiencia visible y el funcionamiento básico. No publica la aplicación, no actualiza indicadores y no restaura respaldos.

## 2. Inicio y navegación

- [ ] La aplicación abre sin pantalla negra, error rojo ni recarga infinita.
- [ ] El título y el número de versión son correctos.
- [ ] La guía «Empieza aquí» se entiende y puede ocultarse.
- [ ] Las secciones principales se encuentran sin instrucciones externas.
- [ ] Volver atrás, recargar y abrir un enlace no dejan la aplicación bloqueada.

## 3. Vista en computadora

- [ ] El estado de actualización distingue claramente al día, revisar pronto y pendiente.
- [ ] La tabla de los 12 indicadores conserva encabezados, fechas y columnas legibles.
- [ ] «Mis indicadores» respeta el máximo recomendado de seis favoritos.
- [ ] El calendario, las fichas y el explorador no se cortan ni se superponen.
- [ ] Las tarjetas muestran valor, unidad, fecha y fuente sin texto truncado importante.
- [ ] La lectura FranQuestions, las señales relacionadas y las advertencias se despliegan correctamente.

## 4. Vista en teléfono

- [ ] No existe desplazamiento horizontal involuntario en la página.
- [ ] Las tarjetas se apilan y siguen siendo legibles.
- [ ] Los botones y selectores se pueden pulsar sin ampliar la pantalla.
- [ ] Con la interacción del gráfico desactivada, deslizar sobre un gráfico desplaza la página normalmente.
- [ ] Al activar zoom y movimiento, el gráfico responde y el control permite volver al desplazamiento normal.
- [ ] Las tablas no atrapan el gesto vertical; pueden consultarse sin impedir seguir bajando.
- [ ] La comparación de señales muestra una alternativa legible si el navegador no admite WebGL.
- [ ] Ningún mensaje, menú flotante o botón tapa información esencial.

## 5. Credibilidad de los datos

- [ ] Aparecen los 12 indicadores previstos.
- [ ] Cada indicador muestra valor, unidad, periodo, fuente y enlace oficial correctos.
- [ ] El estado de vigencia concuerda con la fecha oficial o la regla operativa documentada.
- [ ] Las advertencias metodológicas aparecen donde corresponde.
- [ ] Un cambio extremo se presenta como señal para revisar, no como conclusión causal.
- [ ] Las comparaciones respetan la frecuencia de cada serie y no mezclan periodos incompatibles.

## 6. Descargas

- [ ] El panorama PDF abre y conserva textos, acentos, tablas y saltos de página.
- [ ] La tabla compatible del calendario (`.csv`) conserva columnas y caracteres españoles.
- [ ] La comparación de indicadores (`.csv`) conserva fechas, valores y posiciones estandarizadas.
- [ ] El calendario (`.ics`) ofrece abrir o importar eventos.
- [ ] Los nombres descargados identifican el contenido y la fecha.

## 7. Actualizador local privado

- [ ] El actualizador se abre únicamente en la computadora local.
- [ ] La vista previa identifica el indicador y cuenta las observaciones.
- [ ] La comparación separa observaciones nuevas, revisiones y filas sin cambios.
- [ ] Un archivo idéntico indica que no hace falta incorporarlo.
- [ ] Ningún cambio se incorpora sin confirmación humana explícita.
- [ ] El historial registra el resultado y las filas recibidas/escritas.

## 8. Respaldo y recuperación

- [ ] Existe al menos un respaldo reciente de la base local.
- [ ] El respaldo puede descargarse y guardarse sin intentar abrirlo como documento.
- [ ] La recuperación exige selección explícita y doble confirmación.
- [ ] La restauración solo se prueba sobre una copia de ensayo, nunca sobre la base principal durante esta revisión.

## 9. Defectos encontrados

| Severidad | Área | Descripción | Evidencia o captura | Estado |
|---|---|---|---|---|
| Crítica / Alta / Media / Baja |  |  |  | Pendiente / Corregido / Aceptado |

Guía de severidad:

- **Crítica:** impide abrir, muestra datos incorrectos o permite alterar datos sin control.
- **Alta:** bloquea una función principal o hace inutilizable la experiencia móvil.
- **Media:** dificulta una tarea, pero existe una alternativa clara.
- **Baja:** detalle visual o de redacción que no impide completar la tarea.

- [ ] **Rechazada:** existe un defecto crítico/alto o faltó una parte obligatoria de la revisión.
